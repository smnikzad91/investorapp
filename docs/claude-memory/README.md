# Claude memory snapshot

These files are a copy of Claude Code's persistent memory for this project, exported so the
context travels with the repo (Claude's own memory store is local to the machine it ran on, keyed
by working-directory path — it won't automatically be available on a different machine or path).

They're a snapshot as of the date below, not live — Claude's actual memory may have moved on since.
If you're continuing this project with Claude Code on another machine, point it at this folder
early in the conversation (or just mention it exists) so it can read itself back in.

Snapshot date: 2026-09-13

- `MEMORY.md` — index of the entries below
- `project_tradebot_investor.md` — main project memory: scope, spec revision history, decisions
- `reference_android_app_prompt.md` — where the spec file lives and how its naming behaves
- `reference_github_investorapp.md` — this repo's location or branch
- `feedback_local_properties_tracked.md` — why `local.properties` is committed here, not gitignored
- `env_no_local_android_build.md` — a note about the *original* dev machine's shell tooling; likely
  doesn't apply as-is to whatever machine you're reading this on
